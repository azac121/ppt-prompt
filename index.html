🔹 前置准备：必须先安装 Skill

本工具依赖豆包技能：ppt-master，没有安装将无法执行HTML转PPT。

  1. 打开豆包网页版 / PC客户端
  2. 左侧【技能广场】搜索：ppt-master
  3. 点击添加技能，开启技能调用权限（免费）
  4. 确认聊天框上方可以看到 ppt-master 已启用

🔹 标准制作顺序（不要乱序）

①选题评析 → ②PPT完整大纲 → ③上传参考PPT提取风格规范 → ④逐页生成HTML单页代码 → ⑤SVG配图生成 → ⑥调用ppt-master转为PPT → ⑦出问题用复盘模板修复

🔹 重要限制

  • ppt-master 只支持单页转换，不支持一次性批量转全部页面
  • 画布固定：16:9（1920×1080）
  • 不支持外部图片链接，图片必须转base64内嵌进HTML
  • 转换失败大多是CSS写法、尺寸单位不规范导致

🔹 按钮说明

  • ①选题评析Prompt：输入主题，让AI给你4-6个选题并评析优劣
  • ②详细大纲Prompt：确定选题后，输出逐页汇报大纲+口述稿
  • ③风格提取Prompt：上传参考PPT，提取字体、配色、版式规范
  • ④HTML生成Prompt：单页PPT的固定尺寸HTML代码
  • ⑤复盘沉淀Prompt：转PPT出错时，用来修复HTML
  • ⑥SVG绘图Prompt：生成流程图、架构图矢量图
  • ⑦单页转PPTPrompt：发给豆包，调用ppt-master执行转换

⚠️ 常见踩坑清单

  1. 技能没装：搜不到ppt-master → 更新豆包客户端，网页版优先
  2. 转换后排版乱飞：HTML里不能用 %、vw、vh、rem，全部px固定尺寸
  3. 图片不显示：不能写http图片链接，必须base64嵌入
  4. 字体缺失：尽量使用系统自带无衬线字体，避免小众字体
  5. 一次粘贴多页HTML：ppt-master只认单页，多页会报错
